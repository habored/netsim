📌 Aide générale

🎯 Objectif du jeu

Configurez un réseau et valider les flags en virifiant la connectivité avec la commande ping...

🎮 Comment jouer ?

Mode configuration

  • Si l'élément cliqué est encadré en vert : vous pouvez le configurez
  • Si l'élément cliqué n'est pas encadré en vert : vous pouvez seulement consulter sa configuration
  • Les machines disposent de paramètres différents selon leur rôle dans le réseau

Mode simulation

  • Le mode simulation permet d'exécuter étape par étape la dernière commande console lancé

🔍 Comment diagnostiquer un problème

  • Vérifiez les IP et les masques : les deux machines sont-elles dans le même réseau ?
  • Testez les ping local
  • Testez les ping distant
  • Vérifiez les routes
  • Vérifiez les gateaways
  • Regardez les tables de routage
  • Vérifiez les firewalls
