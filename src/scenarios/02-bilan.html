🧩 Ce que vous avez découvert

Dans ce scénario, certaines machines semblaient correctement connectées au switch…mais la communication échouait malgré tout ❌

Vous avez dû analyser les adresses IP et les masques afin d’identifier les erreurs de configuration réseau.

Machine Adresse IP initiale Masque initial Problème
PC de Bob 192.168.1.0 255.255.255.0 Adresse réseau ❌
PC d'Alice 192.168.1.1 255.255.255.0 Aucun problème ✔️
PC prof 192.168.2.255 255.255.0.0 Mauvais réseau + masque incorrect ❌
PC 192 255.255.1.192 255.255.1.0 Mauvais réseau + masque incorrect ❌

📖✏️ À retenir

  • Toutes adresses IP des machines doivent partager le même net ID pour être sur le même réseau local.
  • Avec le masque 255.255.255.0, les trois premiers octets représentent le réseau.
  • Dans le réseau 192.168.1.0/24, les adresses utilisables vont de 192.168.1.1 à 192.168.1.254.
  • L’adresse 192.168.1.0 est réservée pour identifier le réseau : c’est l’ adresse réseau.
  • L’adresse 192.168.1.255 est réservée pour envoyer un message à toutes les machines du réseau : c’est l’ adresse de broadcast.
  • Une machine ne peut pas communiquer correctement si son adresse IP ou son masque sont invalides.
  • Un masque incorrect peut faire croire à une machine qu’elle appartient à un autre réseau.
  • La commande ping est exécutée depuis un PC source et requiert de préciser l'adresse IP du PC dont on cherche s'il est atteignable depuis le PC source.
