🔍 Ce que vous avez observé

Dans ce scénario, Alice était connectée à un réseau local, mais le serveur se trouvait sur un autre réseau. Malgré une connexion physique via plusieurs équipements, la communication ne fonctionnait pas immédiatement.

  • Le PC d’Alice était dans un réseau local, d'adresse réseau 192.168.1.0/24.
  • Le serveur était dans un autre réseau local, d'adresse réseau 10.0.0.0/24.
  • Il faut donc utiliser le routeur pour établir la communication.
  • Les passerelles des machines étaient déjà configurées et non modifiables
  • La passerelle du PC d'Alice était correcte : 192.168.1.1 appartient bien au réseau 192.168.1.0/24
  • La passerelle du serveur était correcte : 10.0.0.1 appartient bien au réseau 10.0.0.0/24
  • Le routeur possédait deux interfaces à configurer
  • Pour qu'un ping réussisse, il faut que les routes aller et retour soient correctement configurées entre les réseaux.

🏁 Ce que vous avez accompli

  • Vous avez configuré les interfaces du routeur avec des adresses IP valides sur chaque réseau.
  • Vous avez utilisé comme interface du routeur la passerelle utilisée par le PC d’Alice : ainsi, le PC d'Alice peut communiquer avec l'extérieur via le routeur
  • Vous avez utilisé comme interface du routeur la passerelle utilisée par le serveur : ainsi, le serveur peut communiquer avec l'extérieur de son réseau via le routeur
  • Vous avez réussi à établir le chemin complet jusqu’au serveur et récupérer le flag.

📖✏️ À retenir : Le rôle du routeur

  • Un routeur permet de connecter plusieurs réseaux IP différents entre eux.
  • Chaque interface du routeur appartient à un réseau distinct (ex : 192.168.1.1 et 10.0.0.1).
  • Pour sortir de son réseau local, un ordinateur utilise sa passerelle par défaut (gateway).
  • La gateway est généralement l’adresse du routeur dans le réseau local.
  • Le routeur transfère les paquets entre réseaux en fonction de l’adresse IP de destination.
  • Un switch ne suffit pas pour relier deux réseaux différents : seul un routeur permet cette interconnexion.
  • Sans configuration correcte des interfaces et des routes, les réseaux restent isolés même s’ils sont physiquement connectés.
