Dans ce scénario, vous avez montré que vous savez configurer un réseau local autour d'un switch.

📖✏️ À retenir

  • Avec le masque utilisé initialement par le PC d'Alice était 255.255.0.0
  • Les deux premiers octets des adresses IP devaient donc être identiques.
  • Si l'adresse IP 172.16.0.45 était gardée, cela signifie que le net ID était 172.16.0.0
  • Le PC de Bob devait donc être configuré avec une adresse IP du type 172.16.X.Y (où X et Y sont des nombres entre 1 et 254)

✅ Exemple valide

Machine Adresse IP Masque
PC d'Alice 172.16.0.45 255.255.0.0
PC de Bob 172.16.0.46 255.255.0.0

🚀 Dans le prochain scénario...

Les machines seront placées dans des réseaux différents.

Vous découvrirez alors le rôle d'une nouvelle machine : le routeur et l'importance de la passerelle par défaut.

Un routeur est une machine d'interconnexion entre plusieurs réseaux.

Pour appartenir à différents réseaux afin de la faire communiquer, un routeur possède plusieurs adresse IP.
